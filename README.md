# Simple Calculator in Java

## Overview
This is a console-based calculator application developed using Java.  
The calculator performs basic arithmetic operations such as:

- Addition
- Subtraction
- Multiplication
- Division

The program continuously allows users to perform calculations until they choose to exit.

---

## Features
- User-friendly console interaction
- Supports multiple calculations
- Uses switch-case statements
- Handles division by zero
- Loop-based execution

---

## Technologies Used
- Java
- VS Code / IntelliJ IDEA
- Command Prompt / Terminal

---

## Concepts Used
- Scanner Class
- Loops
- switch-case
- Conditional Statements
- User Input Handling

---

## How to Run

### Compile the Program
```bash
javac Calculator.java
```

### Run the Program
```bash
java Calculator
```
